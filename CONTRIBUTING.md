# Contributing to Rick's Parallel

Everyone is welcome: programmers, artists, writers, musicians, playtesters, and people whose main skill is steering an AI well.

## The short version

1. Read the [README](README.md), [docs/STORY.md](docs/STORY.md) and [PROGRESS.md](PROGRESS.md).
2. Find something to do: an open issue, an unchecked Roadmap item, or your own idea (open an issue for it first).
3. Say you are taking it by commenting on the issue.
4. Fork, branch, do the work, open a pull request.

## Using an AI

That is the point of the experiment. Copy the prompt from the README section "Just point your AI at this".

Three requests:

- **Stay in the loop.** You are responsible for what your AI submits. Read it before you open the pull request.
- **Disclose it.** Say in the pull request which parts were AI-generated and with what tool.
- **Keep it small.** A 200-line pull request gets reviewed. A 20,000-line one does not.

## What makes a good contribution

- It does one thing.
- It can be tried: a build step, a screenshot, a short clip, or a model that opens.
- It fits the story bible and the art rules.
- It says what is unfinished.

## Pull request checklist

- [ ] One focused change
- [ ] Linked to an issue
- [ ] Build and tests pass, if any exist yet
- [ ] No secrets, keys or personal data
- [ ] Original work, or assets you have clear rights to (say where they came from)
- [ ] AI involvement disclosed
- [ ] New entry added at the bottom of [PROGRESS.md](PROGRESS.md)

## Assets

Follow [docs/ASSET_PLAN.md](docs/ASSET_PLAN.md) for scale, naming, triangle budgets and export format. One unit is one metre. Models go in `assets/models/` as GLB.

Do not submit assets extracted from other games, or generated to imitate a specific existing game's characters or art.

## Design changes

For anything that changes how the game plays or what the story says, open an issue titled `RFC: <your idea>` and let people weigh in before building it.

## Conduct

Be kind, be specific, and assume the other person is trying to help. Critique the work, never the person. Harassment gets you removed.
